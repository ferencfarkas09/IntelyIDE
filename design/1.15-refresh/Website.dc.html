Built for trust

An agent can propose and edit. Only you commit and push.

  • Hard stops in every mode. Commit, push, merge, rebase and anything inside .git are refused, also in Bypass.
  • Your keys stay yours. SSH keys, cloud credentials and password stores are never read by an agent.
  • Undo any step. Every run keeps checkpoints, so you can go back one step or to the start.
  • Honest about limits. The protections are layered and best effort, and the safety page says where they end.

Questions

Can an agent commit or push?

No. Agents edit files. Committing, pushing and staging are yours, in every mode.

What does it cost?

IntelyIDE is free and open source. Agent runs use your own Claude Code login.

Is there a Windows version?

Not yet. A Windows beta is being worked on; today the app is for macOS.
