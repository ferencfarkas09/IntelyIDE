# IntelyIDE 1.15 refresh: approved mock-ups (reference only, not shipped)

Source of the design canvas the owner approved on 2026-11-12. Four boards, each a static HTML mock-up whose inline styles are the
spec (sizes, radii, spacing, colours as tokens of `intely-theme.css`, which mirrors `ui/src/theme/tokens.css` and `glass.css`):

- `Main.dc.html`: the Agent run window (title bar, rail, runs list, run header, conversation, ask-card, composer, run details, bottom bar).
- `Dashboard.dc.html`: the Dashboard tab.
- `NewRun.dc.html`: the New run dialog.
- `ContextMeter.dc.html`: the context meter popover and the plan-usage popover of the bottom bar, with the bar item states.
- `Website.dc.html`: the IntelyIDE page of the website (1440 px wide; proposed on 2026-11-12, same tokens as the app).

All names and numbers in them are demo data. This branch is a reference for the implementation and is not meant to be merged.
